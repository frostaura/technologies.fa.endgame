# Open questions — founder-owned

1. **When does the repository go private, and is it ever open source?** It is public for free CI
   and unlicensed. The house default is open source; this one departs from it until decided.
2. **Who sends email?** Apps need transactional mail. That is a third external service unless
   Cloudflare's own email sending proves usable (unverified) or the existing FrostAura mail server
   is used. Needed by Phase 4.
3. **The first three invited organisations.** The spec fixes the profile — people the founder
   knows who each run two or more live web products — and that none is invited before FrostAura
   and the Crusaders rebuild run on Endgame. The names are his. Needed by Phase 6.
4. **Is the red-lines reading of God mode right?** An agent passed it on conditions
   ([decisions](decisions.md)). A red line is founder territory.
