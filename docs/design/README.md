# Design source

`canvas/` holds the source of the console design the founder approved on 2026-11-24: six screens
and the iconography sheet, as the HTML the design canvas renders. They are the reference for look,
layout, copy tone and motion. They are not application code, they contain sample figures, and
nothing imports them. The brand mark and icon sprite the product actually uses are in
`src/frontend/public/brand/`.

| File | Screen |
| --- | --- |
| `Main.dc.html` | Home — the living org chart and the docked conversation |
| `Start.dc.html` | Naming the organisation and describing an idea |
| `Verdict.dc.html` | A research verdict, its evidence, and the overrule |
| `Employee.dc.html` | One employee: job, track record, memory |
| `App.dc.html` | One app: health, a plain-language question, running, sharing |
| `Credits.dc.html` | Balance, cascading budgets, estimates, overdraft |
| `Icons.dc.html` | The mark and the 24-icon set |
